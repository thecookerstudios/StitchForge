# Thread libraries

CSV thread charts that ship inside StitchForge. They appear in the Threads
panel; tick the ones you stock. Format: `code,name,r,g,b`, with optional
`# name:`, `# manufacturer:` and `# licence:` lines at the top.

## Madeira (10 lines, 1,667 colours)

Classic Rayon, Polyneon (also Polyneon Green, #60 and #75, which share the
numbers), Frosted Matt, Fire Fighter, Sensa Green, Burmilana, BurmilanaCo,
Supertwist, FS Metallic and Polyester CR Metallic.

- **Codes and colour names** are the ones Madeira publishes for ordering
  (madeirausa.com, November 2026).
- **Screen colours (r,g,b)** were sampled by StitchForge from Madeira's
  product photos. They are approximate, good for previews and picking, not
  dye-accurate. Check important matches against a physical colour card.
- Rows named "(colour unverified)" had a photo that did not match its name.
  Automatic matching skips them, and variegated threads (ombre, multi,
  astro, melange), but you can still pick them by hand.
- Madeira and the thread line names are trademarks of their owners.
  StitchForge is not affiliated with or endorsed by Madeira.

A copy of a library with the same file name in your own
`StitchForge/Thread libraries` folder takes the place of the built-in one.
